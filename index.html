What we do

Three lines of work. Products you can run, engineering that puts research into practice, and tools so agents can act without inheriting the host.

Products

We ship AI-native products. The model is in the artefact — a shared canvas, a form, a research workspace — not a chat panel glued to the side.

Applied research

Research here means applied engineering: take a method, put it in a running system, keep the boundary honest. No papers, no leaderboards, no evaluation claims.

Tools for agents

Open source under Apache-2.0. Diagrams below follow the public READMEs — host and guest, then the credential broker — not invented UI.

Vmette

Hardware-isolated microVM sandbox for running local AI agents on macOS. Untrusted work runs in a Linux VM with its own kernel, via Apple’s Virtualization.framework, not a container that shares yours. Network is off until you pass --net. Also an MCP server.

github.com/chamuka-inc/chamuka-vmette
Docs

Conduit and CredVault

Conduit is a declarative action layer for AI agents over REST and MCP. A new integration is a set of manifests, not a code change. It does not store credentials.

CredVault is the vault: per-end-user OAuth tokens and API keys, encrypted at rest, kept valid across expiry and rotation. Conduit asks it for a token, then calls the API.

github.com/chamuka-inc/chamuka-conduit
github.com/chamuka-inc/chamuka-credvault

Agent Run

Unattended runner for coding agents with rate-limit retry and verify-fix loops. The binary is still claude-run: retry, verify, review, and a YAML pipeline.

Skills

Reusable skills and reference guides for coding agents. A Claude Code plugin of SKILL.md files that conform to the Agent Skills specification.

Plane

Ephemeral compute platform built on Plane and OCI containers, with tiered isolation. Hard fork of jamsocket/plane, plus an in-sandbox HTTP daemon, egress proxy, and operator tooling.

Open source and principles

Everything listed here is Apache-2.0, except DrawIt, which is not public yet. Daybreak is brand infrastructure, not a product.

Apache-2.0
Public repositories ship under the Apache License 2.0. Forks of Daybreak must rebrand; the names and marks are not a licence to look like Chamuka Labs.
Plain first
Say what the thing is in one sentence. Experiments stay labelled experiments. We do not invent customers, logos, testimonials, or metrics.
Applied, not published
Research means engineering that runs. We do not claim papers, benchmarks, or evaluation results.
